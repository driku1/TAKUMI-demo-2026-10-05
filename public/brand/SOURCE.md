# Brand asset source

Accenture wordmark paths sourced from the public header at https://www.accenture.com/jp-ja on 2026-10-04.

The header’s expanded wordmark state is frozen using its published CSS positioning (greater-than mark: scale .396, translate 88.5px; text: translateY 0). Paths are unchanged. White lettering and the source purple #A100FF are used on the dark navigation.

The UI uses Inter and Noto Sans JP as freely available alternatives; it does not claim to implement an internal Accenture design system.
